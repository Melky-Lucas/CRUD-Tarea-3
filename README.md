# CRUD de Productos (HTML + CSS + TypeScript)

Proyecto práctico desarrollado con **Git Flow**.

## Cómo ejecutarlo
```bash
npm install
npm run build
# abrir index.html en el navegador
```

## Ramas
- `main`: producción
- `qa`: pruebas
- `develop`: integración
- `feature/*`: nuevas funcionalidades

## Funcionalidades (una por feature)
| Rama | Funcionalidad |
|------|---------------|
| feature/create-product | Crear productos |
| feature/edit-product | Editar productos |
| feature/delete-product | Eliminar productos |
| feature/search-filter | Buscar y filtrar por categoría |
| feature/local-storage | Persistencia con localStorage |
